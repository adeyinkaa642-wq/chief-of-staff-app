What happens to your data

Plain answers, no marketing.

Stored on your device only: your profile, saved memories, recent chat, and API key live in this browser's local storage. The web page that serves this app contains none of your personal information, so other visitors cannot see it.
Sent to your AI provider: every message you send, plus your profile and saved memories, is sent to the AI provider you chose (OpenAI or Google Gemini) to generate each reply. Your browser talks directly to that provider. The page is configured to block connections to anywhere except OpenAI, Google Gemini, the public price feeds, and GitHub (only if you turn on sync). Your API key and encrypted data are also included in the sync file sent to GitHub if sync is enabled.
Bitcoin price: the app asks Coinbase (or CoinGecko as a backup) for the public BTC price. That request contains none of your information.
Sync (only if you turn it on): your data is encrypted on your device and the encrypted file is stored in your own private GitHub gist. GitHub sees only ciphertext. A strong passphrase matters, because it is the only thing protecting that file if someone ever got the gist link.
Gemini free tier: Google may use content sent with a free Gemini key to improve its products. Use a free Gemini key only for testing with fictional data.
OpenAI's retention: by default OpenAI says API data is not used to train its models and may be kept up to 30 days for abuse monitoring, then deleted. Check OpenAI's current policy and your account's data controls, as terms can change.
Case mode: messages sent in Case mode are not saved to memory, are not written to storage on this device, and are gone when you reload or close the page. While Case mode is on, they are sent to the AI provider, along with your profile and saved memories, and earlier case messages are included as context for follow-up questions. They stay visible on screen until you reload. When you turn Case mode off, case messages are no longer included in the context sent with ordinary messages. The provider still receives them while Case mode is on and handles them under its own retention policy. Use initials or placeholders instead of real names, and follow your department's and bar's rules on AI use.
Limits: memory is per browser and per device. Clearing browser data erases it, so use Backup regularly. Anyone who can use your unlocked browser can read it. Use a passphrase. This tool gives structured thinking, not legal, tax or investment advice.

Sync your devices

Keeps your profile, memories, Bitcoin log and fitness log the same on your phone and computer. Chat history stays on each device.

How it stays private: everything is encrypted on your device with your passphrase before it leaves. It is stored as unreadable ciphertext in a private "secret gist" in your own free GitHub account. GitHub, and anyone else, cannot read it. There is no server of ours.
One-time setup (about 3 minutes):
1. Create a free account at github.com (or sign in).
2. Go to github.com/settings/tokens/new?scopes=gist&description=Chief%20of%20Staff (type this in your browser) → choose No expiration → tick only gist → Generate token → copy it.
3. Paste it below. On your second device do the same, with the same passphrase.
Disconnecting leaves the encrypted copy in your GitHub account. You can delete it at gist.github.com. Syncing runs automatically a few seconds after each change and whenever you open the app.
